Frequently Asked Questions

Is Flashforge IDE really free?
Yes! Flashforge IDE is completely free for all individual users and students. Only institutions pay ₹5,000/month for multi-user management, faculty provisioning, and admin dashboards.
How do I configure my own API key?
Open Flashforge IDE → Go to Models marketplace → Add your Gemini or OpenAI API key → The AI Chat will use your personal key. You can also use Ollama for completely free local models with no API key needed.
What are the system requirements?
Windows 10/11 (64-bit), 4 GB RAM minimum (8 GB recommended), 200 MB disk space. For Ollama local models, 8 GB+ RAM recommended.
How do I install Flashforge IDE?
Download the installer from this website → Run Flashforge-IDE-Setup-1.0.0.exe → Follow the setup wizard → Launch and login with your credentials. Takes about 2 minutes.
I'm an institution. How do I subscribe?
Install Flashforge IDE → Click "Register Institution" on the login screen → Fill in your details → Pay ₹5,000/month via Razorpay inside the IDE → Provision faculty via CSV upload → Done!
Can I use Flashforge IDE offline?
Yes! Install Ollama for offline AI chat. All other features (editor, terminal, assignments, skills) work without internet. Online models (Gemini/OpenAI) require internet.
Does it work on Mac or Linux?
Currently only Windows (x64) is supported. Mac and Linux support is planned for future releases.
